# 站点密码填充器

基于 Tampermonkey / Violentmonkey 的浏览器用户脚本，用于在网站登录页自动填充用户名和密码，支持多站点账号隔离存储、AES 加密、管理面板和导入导出。

## 功能特性

- **自动填充**：页面加载后自动探测并填充登录表单中的用户名和密码。
- **手动触发**：支持 `Ctrl + Shift + F` 快捷键或油猴菜单命令手动填充。
- **多站点隔离**：按 `协议//主机名:端口` 生成站点 Key，不同站点账号互不干扰。
- **AES 加密存储**：账号密码使用 CryptoJS AES 加密后存储在油猴本地存储中，密码不会以明文形式持久化。
- **主密钥保护**：首次运行需设置主密钥，用于加解密所有账号数据。
- **管理面板**：可查看、编辑、删除所有站点账号，支持设置默认账号、查看明文密码、手动指定 CSS 选择器、修改主密钥。
- **导入导出**：支持将所有账号导出为明文 JSON 文件，或从 JSON 文件导入恢复数据。
- **SPA 支持**：监听路由变化（popstate / hashchange），适配动态加载的登录表单。

## 安装方法

1. 安装浏览器扩展：Tampermonkey 或 Violentmonkey。
2. 将本仓库的 `script.js` 复制到油猴的“新建脚本”中，或直接安装。
3. 保存脚本后，刷新目标登录页面。

## 快速开始

### 1. 设置主密钥
首次运行脚本时，会弹出提示要求设置**主密钥**。主密钥用于加密本地保存的账号密码，请妥善保管，不可找回。

### 2. 添加账号
打开油猴菜单 → “账号管理面板”，在右侧输入用户名和密码，点击“新增账号”保存。新增的账号默认设为当前站点的默认账号。

### 3. 自动填充
若当前站点已加入自动填充白名单，页面加载后会自动填充；也可随时使用 `Ctrl + Shift + F` 或油猴菜单“手动填充账号密码”触发。

## 管理面板功能

| 操作 | 说明 |
|------|------|
| 左侧站点列表 | 查看所有已保存站点的账号 |
| 右侧账号列表 | 当前站点的所有账号，可设置默认账号 |
| 👁️ 查看密码 | 点击眼睛图标，以明文短暂显示密码（8 秒后自动隐藏） |
| 改密码 | 修改指定账号的密码 |
| 设为默认 / 取消默认 | 切换该账号是否为自动填充时优先使用 |
| 删除 | 删除指定账号 |
| 导出 JSON | 导出所有站点账号为明文 JSON 文件（含明文密码，请妥善保管） |
| 导入 JSON | 从 JSON 文件导入账号数据，会用当前主密钥重新加密存储 |
| 清空全部 | 删除所有账号、选择器和白名单数据（不可撤销） |
| 手动指定选择器 | 为当前站点自定义用户名/密码输入框的 CSS 选择器 |
| 修改主密钥 | 更换主密钥。更换前请先导出明文备份，否则旧加密数据将无法解密 |

## 注意事项

1. **主密钥更换风险**：更换主密钥后，之前用旧主密钥加密的账号密文将无法解密。建议先点击“导出 JSON”备份明文数据，再更换主密钥，最后用“导入 JSON”恢复。
2. **导出文件包含明文密码**：导出的 JSON 文件中密码为明文，请妥善保管，不要泄露给他人。
3. **仅支持油猴环境**：脚本依赖 `GM_setValue`、`GM_getValue` 等油猴 API，必须在 Tampermonkey / Violentmonkey 等支持的扩展中运行。
4. **动态页面**：脚本会监听页面路由变化，适配单页应用（SPA）中动态渲染的登录表单。
